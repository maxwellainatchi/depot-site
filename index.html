Every package manager.
One window.

Depot shows what is installed, what has updates, and what happened, across Homebrew, the Mac App Store, npm, pipx, Cargo, winget and more, on this computer and on your other machines. To change anything, it runs the package manager's own command, and shows you exactly what it ran.

See what it does Supported managers

Every command is visible

Depot never changes anything except by running a package manager's command, and each one appears in the operation log exactly as it was run. History keeps the log for every check, install, update and removal.

$ brew upgrade git
git 2.47.1 -> 2.48.0
$ pipx upgrade ruff
upgraded package ruff from 0.8.0 to 0.8.1

Nothing is hard-coded per manager

Each adapter declares what its manager can do: pin, roll back, repositories, services. The interface only shows the controls that apply, so Homebrew gets taps and services, and npm doesn't pretend to.

What it does

One place to see and change everything you've installed

The whole machine at a glance

The Dashboard shows updates available, packages installed, package managers found, warnings and recent activity. Updates are grouped by source: select all, only majors or one manager, pin, skip a version, or read the release notes in place.

Everything installed, in one table

Every package from every source, with its version, status and size. The same software installed through two managers shows as one row that names both. Export a list, import it on another machine.

Search every source at once

Discover searches all your package managers together, notes when something is already installed elsewhere, and shows the exact install command before it runs.

A history you can undo

Every check, install, update and removal, with its full log, and a revert where the package manager can do one.

Know what needs attention

Health lists installed packages with known vulnerabilities, from OSV.dev, or that their manager has deprecated, with the update that fixes each one. It also finds disk space the managers can give back, such as old versions, download caches and dependencies nothing needs, and frees it with their own cleanup commands.

See how it all changes

Insights charts what is installed and what happened to it: changes per week, installs per month, size and count per manager, the largest and most-updated packages, and a dependency graph you can explore.

From the menu bar

The tray icon shows the pending-update count, the top updates, and Update all, without opening the window.

Scheduled checks

Per source, choose to install updates automatically, be notified, check quietly, or not check. A single package can always or never update automatically, whatever its source does.

Lists

Named sets of packages, installed or not: "Want to try", "Essentials", an uninstall queue. Each list exports and imports on its own.

Pin, skip or ignore

Hold a package at its version, skip one release, or stop hearing about a package's updates altogether.

Command palette

Press ⌘K (Ctrl+K on Windows) to jump to any screen, package, update or action by typing.

Keeps itself current

Depot checks for its own new versions and installs them when you say so, from Settings.

Light and dark

Depot follows your system appearance, or the one you pick in Settings. This page does too.

Other machines

Your home server and your other Macs, from the same window or your phone

Every machine on the Dashboard

Add a Mac or Linux machine you can reach over SSH, and Depot installs its small agent there itself. The Dashboard then sums up each machine: updates, packages, package managers, warnings and recent activity.

Work on it as if you were there

Pick a machine and every screen switches to it. Installs, updates and removals run on that machine's own queue and finish even if Depot closes, and every command still appears in the log exactly as it ran. Windows machines and changes that need an administrator password are next.

From your phone in progress

An Android app reaches the same machines from your pocket. It has SSH built in, with its own key that never leaves the phone, and it asks you to check a machine's fingerprint before trusting it. Pick a machine to see its overview, updates and packages, and to update, install or remove.

AI assistants

Let Claude check for updates, on your terms

Depot is an MCP server

An assistant such as Claude Code or Claude Desktop can list packages, updates and warnings, and queue installs, updates and removals, on this computer and on your other machines.

Access is off until you turn it on in Settings, as read only or full access. What an assistant queues goes through Depot's one queue and shows in History as "AI assistant".

# Claude Code, on a Mac
claude mcp add depot -- \
  /Applications/Depot.app/Contents/MacOS/depot --mcp

# Read
list_packages  list_updates  get_health
search_packages  get_history  list_machines

# Change, when you allow it
install_packages  update_packages
uninstall_packages  check_for_updates

Bring your own

Any command-line package manager that prints JSON can be added without changing Depot. Describe its commands in a TOML manifest and drop it in ~/.config/depot/adapters/, or load it from Settings.

id        = "pipx-manifest"
binary    = "pipx"
detect    = "pipx --version"

[commands]
list      = "pipx list --json"
install   = "pipx install {name}{version:==}"
upgrade   = "pipx upgrade {name}"
uninstall = "pipx uninstall {name}"

[parse.list]
items   = "venvs.*"
version = "metadata.main_package.package_version"
