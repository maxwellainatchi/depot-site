Every package manager.
One window.

Depot shows what is installed, what has updates, and what happened, across Homebrew, the Mac App Store, npm, pipx, Cargo, winget and more. To change anything, it runs the package manager's own command, and shows you exactly what it ran.

Every command is visible

Depot never changes anything except by running a package manager's command, and each one appears in the operation log exactly as it was run. History keeps the log for every check, install, update and removal.

$ brew upgrade git
git 2.47.1 -> 2.48.0
$ pipx upgrade ruff
upgraded package ruff from 0.8.0 to 0.8.1

Nothing is hard-coded per manager

Each adapter declares what its manager can do: pin, roll back, repositories, services. The interface only shows the controls that apply, so Homebrew gets taps and services, and npm doesn't pretend to.

What it does

One place to see and change everything you've installed

The whole machine at a glance

The Dashboard shows updates available, packages installed, package managers found and recent activity. Updates are grouped by source: select all, only majors or one manager, pin, skip a version, or read the release notes in place.

Everything installed, in one table

Every package from every source, with its version, status and size. The same software installed through two managers shows as one row that names both. Export a list, import it on another machine.

Search every source at once

Discover searches all your package managers together, notes when something is already installed elsewhere, and shows the exact install command before it runs.

A history you can undo

Every check, install, update and removal, with its full log, and a revert where the package manager can do one.

From the menu bar

The tray icon shows the pending-update count, the top updates, and Update all, without opening the window.

Scheduled checks

Per source, choose to install updates automatically, be notified, check quietly, or not check. A single package can always or never update automatically, whatever its source does.

Lists

Named sets of packages, installed or not: "Want to try", "Essentials", an uninstall queue. Each list exports and imports on its own.

Light and dark

Depot follows your system appearance, or the one you pick in Settings. This page does too.

Bring your own

Any command-line package manager that prints JSON can be added without changing Depot. Describe its commands in a TOML manifest and drop it in ~/.config/depot/adapters/, or load it from Settings.

id        = "pipx-manifest"
binary    = "pipx"
detect    = "pipx --version"

[commands]
list      = "pipx list --json"
install   = "pipx install {name}{version:==}"
upgrade   = "pipx upgrade {name}"
uninstall = "pipx uninstall {name}"

[parse.list]
items   = "venvs.*"
version = "metadata.main_package.package_version"
